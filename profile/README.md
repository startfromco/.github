## What this is

This organization is the hub for everything we open source: the tools we build for ourselves, and the products we ship to others. If we've made it public, it lives here.

## Where to look

- **Repositories** – browse the [repositories](https://github.com/orgs/startfromco/repositories) for current projects. Pinned repos are the best place to start.
- **Issues & discussions** – found a bug or have an idea? Open an issue on the relevant repo.
- **Contributing** – pull requests are welcome. Check each repository's `README` and `CONTRIBUTING` file for how to get set up.

## Working with us

Each project is licensed individually; check the `LICENSE` file in the repo you're using. For security issues, please use the repository's private security advisory flow rather than a public issue.
